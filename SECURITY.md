# Security

OpenLobs holds people's connections to their apps, so we take security reports seriously and thank you for them.

## Report a problem

Please **do not open a public issue** for a security problem.

Use GitHub's private report: open the **Security** tab of this repository and choose **Report a vulnerability**. Include what you found, how to repeat it, and what you think the impact is. A short, clear description is enough.

We aim to reply within a few days, to tell you what we decide, and to credit you when the fix is out if you would like that.

## What counts

For example: reading or changing another person's data, getting around the approval gate, leaking a key or token, running something the person did not approve, making the server fetch private network addresses, or a way to make a shared skill or agent do more than it shows.

## Please do not

- Test against other people's accounts or data.
- Run anything that degrades the service for others.
- Share the problem publicly before it is fixed.

## Keys

If you find a real key or token committed in this repository, report it the same way. We will revoke it.
